# Identity model

The latest supplied framework already maps five institution roles for all 100 countries, plus an additional science/trade table with generic fallbacks. The UI consumes those tables rather than replacing their gameplay. The ministry table is scenario data, not a guarantee of current organisational structure.

The US Department of Defense display name is an explicit user-requested override of the supplied “Department of War” label. Russia's foreign-intelligence panel uses SVR, and domestic security mentions FSB alongside the interior ministry. The distinction between foreign intelligence and domestic security is useful in the new framework, but each screen aggregates game functions beyond any one real agency's remit.

Reference checks: [CIA overview](https://en.wikipedia.org/wiki/Central_Intelligence_Agency), [Russian Foreign Intelligence Service](https://en.wikipedia.org/wiki/Foreign_Intelligence_Service_%28Russia%29), [Reuters reporting on FSB](https://www.reuters.com/business/aerospace-defense/russias-fsb-targets-foreign-embassies-moscow-cyber-espionage-campaign-microsoft-2025-07-31/). These checks do not validate all ministry names in the supplied source.

Art: original built-in image generation, 10 atlases × 10 countries, in framework order. Brief: fictional contemporary government council advisers; locally related capital architecture; cinematic teal/amber lighting; no real leaders. Small incidental generated background details should not be read as official emblems or exact facilities. The actual national flag and name are displayed separately by the game.
